# Chapter 1 Lab: Databricks Runtime for ML and Cluster Selection

**Estimated time:** 15 minutes

## Exercise

Create a Databricks Runtime for ML single-node cluster in Community Edition, launch a notebook, and inspect pre-installed library versions with %pip list

## Key takeaway

Match the runtime and cluster shape to the workload: Databricks Runtime for ML plus single-node clusters for in-memory single-machine training, multi-node for distributed Spark workloads.
