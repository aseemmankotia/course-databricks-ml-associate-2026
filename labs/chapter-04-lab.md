# Chapter 4 Lab: MLflow Tracking, Model Registry, and Unity Catalog Governance

**Estimated time:** 25 minutes

## Exercise

Log an MLflow run with autologging enabled, register the resulting model to Unity Catalog, and assign a Champion alias to the version

## Key takeaway

MLflow Tracking captures experiment history while the Model Registry / models in Unity Catalog governs versioning and lifecycle promotion via aliases, not the older stage names.
