# Chapter 3 Lab: Feature Engineering in Unity Catalog

**Estimated time:** 25 minutes

## Exercise

Create a feature table using the Feature Engineering client in Unity Catalog, write features, and create a training set using FeatureLookup

## Key takeaway

Feature Engineering in Unity Catalog with FeatureLookup provides consistent, governed, point-in-time-correct features across training and serving, unlike ad-hoc feature joins.
