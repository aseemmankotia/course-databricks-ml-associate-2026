# Chapter 11 Lab: Batch, Streaming, and Real-Time Model Serving

**Estimated time:** 22 minutes

## Exercise

Load a registered Unity Catalog model as a Spark UDF to score a batch DataFrame, then deploy the same model to a Model Serving endpoint for real-time REST calls

## Key takeaway

Choose Model Serving for low-latency real-time inference, and Spark UDF batch scoring for high-throughput bulk inference — the exam consistently tests this distinction.
