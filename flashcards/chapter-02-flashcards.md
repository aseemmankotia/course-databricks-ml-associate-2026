## Chapter 2: AutoML: Baseline Models and Generated Notebooks — Flashcards

| # | Front (Question) | Back (Answer) |
|---|-----------------|---------------|
| 1 | Default primary metric for AutoML classification experiments? | F1 score (weighted). Exam tip: regression defaults to R2, forecasting defaults to SMAPE. |
| 2 | What happens when a dataset is too large to fit in the driver node's memory during AutoML training? | AutoML automatically samples the dataset down before training the classical ML models. Exam tip: this is a known limitation — very large datasets are sampled, not distributed across the cluster during model fitting. |
| 3 | Which three problem types does Databricks AutoML support? | Classification, Regression, Forecasting. Exam tip: clustering, image classification, and NLP are NOT supported. |
| 4 | AutoML Python API call to launch a regression experiment? | from databricks import automl; summary = automl.regress(train_df, target_col='price', timeout_minutes=30). Exam tip: analogous calls are automl.classify() and automl.forecast(). |
| 5 | Parameter used to prevent AutoML from using a column (e.g., an ID column) as a feature? | exclude_cols=['customer_id'] passed to classify()/regress()/forecast(). Exam tip: UI equivalent is deselecting the column in 'Advanced Configuration'. |
| 6 | How do you get the best model's generated notebook from an AutoML API summary object? | summary.best_trial.notebook_id (or click 'View Notebook' from the leaderboard). Exam tip: every trial — not just the best — has its own generated source notebook. |
| 7 | Classification/Regression vs Forecasting — key input parameter difference? | Classification/regression need only target_col; forecasting additionally requires time_col and a horizon/frequency setting. Exam tip: forecasting uses Prophet/ARIMA under the hood, not sklearn. |
| 8 | AutoML vs manual MLflow tracking — who logs the trial runs? | AutoML automatically logs every trial (params, metrics, model artifact, source notebook link) to MLflow under one experiment. Exam tip: no manual mlflow.log_* calls are needed for AutoML trials. |
| 9 | Why can't AutoML be used for deep learning tasks like image classification? | AutoML's search space is limited to classical ML libraries (sklearn, xgboost, lightgbm) plus Prophet/ARIMA for forecasting — there is no neural network search space. Exam tip: adding a GPU cluster does not add deep learning support. |
| 10 | What is the 'Data Exploration Notebook' generated by AutoML? | An auto-generated profiling notebook created before training starts, summarizing nulls, distributions, and cardinality per column. Exam tip: it is separate from the per-trial model training notebooks. |
| 11 | What can you do with the exported source notebook for the best AutoML trial? | Clone/export it, then edit feature engineering or hyperparameters directly as normal Python code and re-run it. Exam tip: this is the standard path from AutoML baseline to a tuned production model. |
| 12 | What is the AutoML leaderboard sorted by, and where is it found? | Sorted by the experiment's primary metric across all trials; found in the MLflow experiment UI created by the AutoML run. Exam tip: each row links to that trial's generated source notebook and its MLflow run. |
